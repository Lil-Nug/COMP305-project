# COMP305 Project

## Overview
 This project aims to study the prisoner's dilemma with a focus on trying to understand how different strategies and conditions for the game can influence the outcomes for the game. Specifically, it is going to investigate the iterated prisoner's dilemma and how different strategies can influence the stability of the outcomes under different numbers of repeated interactions. 
The initial working question is:
> How do different strategies affect the outcomes when they're made to repeatedly play the prisoner's dilemma under different conditions?

Here, conditions refer to a varied number of rounds, number of players, payoffs, etc.
The plan is to build upon this question and make it more specific as work is done on the question. For example, we could study under what conditions the outcomes become stable, that is, the outcome for each round eventually becomes constant between each pair of players, etc.
